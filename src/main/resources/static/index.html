📖 용어 사전

주식 기본 용어

매수 (BUY)주식을 사는 것.
매도 (SELL)주식을 파는 것.
지정가 (LIMIT)내가 원하는 가격을 직접 정해서 주문하는 방식. 그 가격 조건이 맞아야 체결돼요.
시장가 (MARKET)가격을 정하지 않고, 지금 거래 가능한 가격에 즉시 체결을 시도하는 방식.
체결 (Fill)매수 주문과 매도 주문의 조건이 맞아 실제로 거래가 성사되는 것.
잔량주문 수량 중 아직 체결되지 않고 남은 수량.
누적체결수량지금까지 체결된 수량을 모두 더한 값.

주문 상태

NEW주문을 만들었지만 아직 서버에 접수되지 않은 상태.
ACCEPTED서버가 검증을 통과시키고 주문을 정상적으로 접수한 상태.
PARTIALLY_FILLED주문 수량 중 일부만 체결된 상태.
FILLED주문 수량이 전부 체결된 상태.
REJECTED서버가 검증에 실패해 주문을 거부한 상태.
CANCELLED주문이 취소된 상태.

FIX 프로토콜 용어

FIX전 세계 금융시장에서 주문·체결 정보를 주고받을 때 쓰는 표준 통신 규격.
ClOrdID클라이언트가 주문마다 붙이는 고유 번호.
거래소 주문번호 (OrderID)서버가 주문을 접수하면서 새로 부여하는 번호.
New Order Single (35=D)신규 주문을 접수해 달라는 요청 메시지.
Execution Report (35=8)주문 접수·거부·체결 결과를 알려주는 메시지. 이 예제에서는 세 가지 경우 모두 이 메시지 하나로 표현해요.
Order Cancel Request (35=F)기존 주문의 취소를 요청하는 메시지.
SENT / RECEIVED이 화면 기준으로 클라이언트가 서버에 보낸 메시지(SENT)인지, 서버로부터 받은 메시지(RECEIVED)인지를 나타내요.
